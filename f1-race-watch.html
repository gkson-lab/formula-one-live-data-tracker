Start the relay
  1. Keep f1-relay.js, f1-race-watch.html and Start Race Watch.bat in the same folder.
  2. Double-click Start Race Watch.bat. The first time it installs what it needs (Node.js must be installed from nodejs.org). It then opens this app in your browser.
  3. Leave the black relay window open during the race. Close it to stop.
Or start it from a terminal in that folder:
npm install ws
node f1-relay.js --open

The first transcript downloads a speech model (about 40 MB for Fast, about 80 MB for Better) and caches it. Radio audio is noisy, so expect some mistakes.

The FIA badge on race control graphics loads the FIA's logo from the web. If it cannot load, a stand-in is shown. You can upload your own image instead (stays in this browser).
